# Tracker — приложение для отслеживания привычек

Учебное iOS-приложение для создания привычек, планирования задач и отслеживания регулярности их выполнения.

## Функциональность

- Создание, редактирование и удаление привычек.
- Создание и управление категориями.
- Настройка расписания выполнения привычек.
- Отметка выполненных привычек.
- Фильтрация трекеров.
- Экран статистики.
- Локализация и поддержка светлой и тёмной тем.
- Сохранение данных между запусками приложения.

## Технологии

- Swift
- UIKit
- Auto Layout
- UICollectionView, UITableView
- Core Data
- MVVM
- XCTest, Screenshot Tests
- Yandex AppMetrica
